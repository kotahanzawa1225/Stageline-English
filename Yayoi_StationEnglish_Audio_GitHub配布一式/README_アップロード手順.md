# Yayoi's Station English 音声｜GitHub Pages アップロード手順

## フォルダ構成（このまま丸ごとアップロード）
```
audio/
└── yayoi/
    ├── index.html   ← 再生ページ（受講者に送るのはこのURL）
    ├── all.mp3      ← 通し版（Audio 01–28・約10分）
    ├── 01.mp3 … 28.mp3  ← トラック別（音量を −16 LUFS に統一済み）
```
全29ファイル・合計約17MB。

## 手順（診断アプリと同じリポジトリ `tools` を使う場合）
1. GitHubのリポジトリ画面 → **Add file → Upload files**
2. この `audio` フォルダを **フォルダごと** ドラッグ＆ドロップ（ブラウザがフォルダ構造を保持してくれる）
   - フォルダごとドロップできない場合：先に「Add file → Create new file」でファイル名欄に `audio/yayoi/.gitkeep` と入力して保存 → `audio/yayoi/` に入ってから Upload files で29ファイルをドロップ
3. 下の **Commit changes** を押す
4. 1〜2分待つ

## 受講者に送るURL
```
https://（GitHubユーザー名）.github.io/tools/audio/yayoi/
```
（末尾の `/` まで。`index.html` は省略可）

## メール本文の例
> 件名：STAGE LINE｜Station English 教材と音声（Audio 01–28）
>
> Yayoiさん
> 教材（PDF）を添付します。音声は下のリンクからスマホでそのまま聞けます。
> https://（上のURL）
>
> ・トラック名をタップで再生。画面を消しても再生は続き、ロック画面から停止・次へができます
> ・Listen & Respond（赤い番号）は「ループ」をONにして、ポーズで声に出す練習を繰り返してください
> ・一度 Safari / Chrome で開いたら「ホーム画面に追加」しておくと、次回からアプリのように開けます

## 公開前チェック（自分のスマホで）
- [ ] URLをタップして開く → トラック一覧が出る
- [ ] トラックをタップ → 再生される。別のトラックをタップ → 切り替わる
- [ ] 画面をロック → 音が続く。ロック画面に「Audio 04 · Listen & Respond …」と一時停止ボタンが出る
- [ ] ループON → 同じトラックが繰り返される
- [ ] 「通しで聞く」→ all.mp3 が再生される
- [ ] 1.0× → 0.8× で遅くなる

## 注意
- **LINE内ブラウザ**で開くと、ロック時に止まることがあります（LINE側の仕様）。「…」→「Safariで開く」を案内してください。メールのリンクから開く場合はこの問題は起きません
- 音声を差し替えるときは、同じファイル名でアップロードし直せばURLは変わりません
- 別の受講者を追加するときは `audio/（名前）/` フォルダを増やし、`index.html` の TOPICS を書き換えるだけで使い回せます
